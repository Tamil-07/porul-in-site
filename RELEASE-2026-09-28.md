## Deployment and verification

```sh
npm run build
npx wrangler whoami
npx wrangler deployments list
npm run deploy
node scripts/check-endpoints.mjs https://porul.in
```

Use the configured production worker, not a temporary account. Record the deployment ID and date here, retain the previous deployment for rollback, verify the apex domain, and recheck Markdown → HTML → Markdown responses for cache separation. A failed crawler check is a remaining edge issue, not permission to disable security globally. Validate HTTP/www/blog redirects separately before claiming those historical findings are fixed.

Protocol references: [llms.txt format](https://llmstxt.org/), [Accept negotiation](https://acceptmarkdown.com/guides/accept-parsing), [Cloudflare Worker-first static assets](https://developers.cloudflare.com/workers/static-assets/routing/worker-script/). The implementation follows RFC-style specific media-range exclusions; an Accept list that permits neither supported representation returns 406.
