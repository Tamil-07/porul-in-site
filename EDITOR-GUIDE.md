# Editor Guide

This guide is intentionally short for Stage 1 because the browser editor is not implemented until Stage 5.

## Current Stage

The project now has the static Astro foundation, local font wiring, navigation, footer, and documentation. There is no CMS screen yet, and no one should publish stories through the browser until Stage 5 is approved and built.

## Later Workflow Preview

When Stage 5 is approved, this guide will become the founder and intern handbook for:

- Publishing a story.
- Marking a story as sponsored.
- Updating the sponsor slot.
- Editing About, The Room, and Sponsor pages.

Until then, content changes should wait so the project does not bypass the PRD stage gates.
